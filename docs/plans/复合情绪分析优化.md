# 复合情绪与 vent/soothe 六维对齐 — 实施清单

本文件对照开发计划，便于复查与后续迭代。

## 已实施

| 项 | 说明 |
|----|------|
| **routing-mixed** | [`src/App.js`](../../src/App.js)：`detectMixedEmotionContrast`（转折标记 + 负向词 + 正向信号）为真时跳过本地「全负面→发泄/安抚」，走流式六维。 |
| **vent-soothe-6d-parity** | 负面路径不再调用已删除的 `handleStartGeneration` / `executeRecommendationPipeline`；选 vent/soothe 后 `setInterventionType` + `setMixMode('generating')`，与正向共用 `StreamingAnalysisCard` → `/api/analyze_mood_stream` → `handleStreamingComplete`。 |
| **streamUserInputForMood** | 干预后缀 + DIY 原料行与流式 `user_input` 一致。 |
| **stream-prompt-mixed** | [`server/llmProxy.js`](../../server/llmProxy.js) 流式 prompt 要求并存/转折时 `patternAnalysis.polarity.type` 为 `mixed`；[`server/prodServer.js`](../../server/prodServer.js) `buildSystemPrompt` 同步说明。 |
| **repair-polarity** | `handleStreamingComplete` 缺 `patternAnalysis` 时默认 `mixed`（非 `negative`）。 |
| **vent/soothe → 推荐** | [`src/engine/vectorEngine.js`](../../src/engine/vectorEngine.js)：`applyInterventionBiasToUserVector` + `evaluateAndSortDrinks(..., interventionType)`，发泄拉向更烈/冷/高酒精感维度。 |
| **Orchestrator** | [`src/agents/core/AgentOrchestrator.js`](../../src/agents/core/AgentOrchestrator.js) 向量排序透传 `options.interventionType`。 |
